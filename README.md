# ThreadLMS - Learning Management System

A comprehensive learning management system built with the MERN stack, designed to provide an interactive and engaging educational experience for students and faculty.

## 🛠️ Tech Stack

### Frontend
- **React** - Component-based UI library for building interactive interfaces
- **TypeScript** - Type-safe JavaScript for better development experience
- **Vite** - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework for responsive design
- **Framer Motion** - Animation library for smooth UI transitions

### Backend
- **Node.js** - JavaScript runtime for server-side development
- **Express.js** - Web framework for building RESTful APIs
- **MongoDB** - NoSQL database for flexible data storage
- **Mongoose** - ODM for MongoDB with schema validation

### Additional Services
- **Cloudinary** - Cloud-based image and video management
- **Gemini AI** - Google's AI for content generation and analysis
- **RSS2JSON** - API for converting RSS feeds to JSON
- **RapidAPI** - Job search API integration
- **Resend** - Email service for newsletters and notifications
- **JWT** - JSON Web Tokens for secure authentication

## ✨ Features

### 🎓 Student Portal
- **Branch-specific Courses** - Access courses relevant to your academic branch
- **Contributions Graph** - Visualize your learning progress and activity
- **Free Newsletter** - Stay updated with educational content and announcements
- **AI-Powered Roadmap** - Node-based learning path generator with refinement capabilities
- **Resume Builder** - Drag-and-drop resume creation with ATS score calculation
- **Job Search** - Find relevant job opportunities based on your skills
- **Branch-specific IDE** - Integrated development environment for coding practice
- **Accomplishments** - Showcase certificates and achievements
- **Grades & Feedback** - Track academic performance and instructor feedback
- **Leaderboard** - Compete with peers and view rankings
- **Personalized Notifications** - Customizable alerts and preferences

### 👨‍🏫 Faculty Portal
- **Course Editor** - Drag-and-drop interface for creating and managing courses
- **AI Quiz Builder** - Generate custom quizzes instantly with AI assistance
- **Sticky Notes (Todos)** - Create and publish notes for students
- **Student Management** - Monitor student progress and performance
- **Discussion Forums** - Engage with students through faculty discussions

### 🤝 Collaboration Features
- **Open Source Projects** - Display and contribute to community projects
- **Collaboration Page** - Connect and work with other users on projects
- **Real-time Interactions** - Seamless communication and collaboration tools

### 🎨 User Experience
- **Enhanced UI/UX** - Modern, intuitive interface with smooth animations
- **Responsive Design** - Optimized for all devices and screen sizes
- **Accessibility** - Inclusive design for all users

## 🏃‍♂️ Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/KhajeeMohammedZunaid/ThreadLms.git
   cd ThreadLms
   ```

2. **Install dependencies**
   ```bash
   # Frontend
   npm install

   # Backend
   cd backend
   npm install
   ```

3. **Environment Setup**
   - Copy `.env.example` to `.env` in backend folder
   - Configure all required API keys and database credentials

4. **Start Development Servers**
   ```bash
   # Frontend (from root)
   npm run dev

   # Backend (from backend folder)
   npm run dev
   ```
